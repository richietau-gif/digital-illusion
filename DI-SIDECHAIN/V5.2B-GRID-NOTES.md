# DI SIDEFX 5.2B — architecture and current implementation

## Product identity
**DI SIDEFX** is a newly identifiable VST3 product, NOT an in-place
upgrade of DI SIDECHAIN. CMake target `DISidefx`, VST3 plugin code `DiFx`,
bundle ID `com.digitalillusion.disidefx`. Original DI SIDECHAIN remains
installable beside it.

## Transport and sequencing
- Original omniGRID-inspired 8 x 16 **trigger** grid, not a copy of its code
  or artwork.
- Rows 1–6: independent ducking voices with their own 8-node envelope,
  depth and length multiplier. Strongest attenuation wins when voices overlap.
- MIDI notes 36–41 trigger duck voices directly; note velocity scales depth.
- Rows 7–8: REVERB and DISTORT FX send gates.
- The musical transport is anchored to Ableton PPQ when sync is on.
  `ShapeSequencer::getStepGeneration()` tracks absolute clock cycles so
  one-step patterns and repeated same-number steps retrigger correctly.
- Four scenes (A–D) store independent grid patterns and per-cell reverb
  reverse toggles, with GUI selection and copy to another scene.
- Factory presets: Classic Duck, Deep Pump, Sidechain 4/4, Breakbeat Pump,
  Pump Rise and Wobble, programmed into the new trigger grid.

## REVERB FX
- A small `<` reverse-before-reverb toggle in each REVERB step.
- Live audio is buffered into preallocated reverse windows matched to the
  musical step duration, up to two seconds; fade at window edges reduces
  discontinuities. No future audio is accessed.
- Five **tonal profiles** (Room, Plate, Hall, Ambient, Space) of a
  JUCE/FreeVerb-style algorithm; Dry/Wet, Length/Size, Decay and enable.
- FX input is gated by the row, while existing reverb tails continue
  receiving zero-input processing after the active step ends.

## DISTORT FX
- Five waveshaping characters: Warm, Acid, Clip, Fold, Modern.
- Fixed 2x oversampling with a 15-tap lowpass FIR, independent stereo
  processing, 7-sample aligned dry path and smooth per-step gating.
- Added plugin reported latency to match dry/wet alignment.
- Drive and Dry/Wet controls; global enable toggles automatically when
  the first effect cell is activated.
- Digital clipping can still occur at high drive or wet amounts: verify
  peak headroom, intersample peaks and alias suppression by ear/measurement.

## State and realtime constraints
- 4 scenes x 8 tracks x 16 steps stored as atomic cell values.
- Per-track shape/depth/length and scene/reverse flags saved in host state.
- Reverse and FIR memory initialized during prepareToPlay, no intentional
  heap allocation in the per-sample FX path.
- Original advanced filter/FX controls currently remain available.
- Dedicated `.disidefx` user preset file extension.
- Experimental branch only, draft PR #14.

## Not yet completed / quality follow-up
- Per-cell velocity, length and shift are defined in `DuckTrackGrid.h`
  but not yet wired to the GUI/DSP; per-track depth/length/shape **are**
  wired and working at code level.
- Reverb profiles are not five distinct algorithm families, and
  length/decay are not calibrated RT60 seconds.
- Variable-length reverse windows are not equivalent to sample-file reverse;
  capture time, discontinuities and phase need listening tests.
- Scene selection is immediate rather than beat-quantized.
- Need actual successful Windows VST3 build, CTest, pluginval and
  Ableton Live 12 validation before making release claims.
- See `SIDEFX-RELEASE-CHECKLIST.md` for ZIP packaging and QA steps.
