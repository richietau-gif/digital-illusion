# DI SIDECHAIN 5.2B — GRID sequencer prototype

Development branch: `feature/di-sidechain-v5.2b-grid` (based on `di-sidechain-5.1-dev`).

## Implemented in the first iteration
- Replace the sequencer's single-lane envelope overview with a three-row, sixteen-column grid.
- Show VOLUME, FILTER and PAN simultaneously, with independent lane colours and per-cell curve-derived intensity.
- Highlight the current transport step (green) and the selected lane/step (orange).
- Click any cell to select its lane and step without inadvertently modifying the stored automation.
- Keep the existing detail curve editor, 16-step DSP/state model, A/B snapshots, presets and filter/FX controls.
- Identify the experimental GUI as version 5.2B.

## Scope and limitations
This is an original layout inspired by the interaction model visible in the supplied omniGRID reference, not a copy of omniGRID artwork or source code. The current processing engine has three modulation lanes, not omniGRID's arbitrary tracks, pads and MIDI clip engine. Each grid cell represents a sidechain modulation curve, not a MIDI note. The active step is derived from the existing DSP transport.

## Validation required before merge
- Windows VST3 compile and pluginval; load in Ableton Live 12.
- Check 50%, 75%, 100% UI scale, clicking all 16 steps and all 3 lanes.
- Verify sequence step-count reductions (1–16), project transport and tempo sync, MIDI/audio triggers.
- Check automation, session reload, preset and A/B state, undo/redo, clipper and saturator.
- Check no new audio-thread allocations or changes to DSP behaviour.

No merge to main and no GitHub Actions build is triggered by this commit.
