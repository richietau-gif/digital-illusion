# Digital Illusion

Audio plugins by Digital Illusion.

## DI SIDECHAIN
JUCE 8 / C++17 VST3 audio effect for Ableton Live 12, with external audio sidechain and MIDI note triggers. The source code is in `DI-SIDECHAIN/`.

The Windows build runs in GitHub Actions; download the VST3 bundle from the latest successful workflow run's Artifacts section. Builds are experimental and require testing before production use.
